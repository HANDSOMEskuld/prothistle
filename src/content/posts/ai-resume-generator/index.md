## 0x0 前言

最近公司在裁员，每个人都人心惶惶。

我也被迫面临失业的风险，遂广投简历试图提前找到一个更好的工作。

众所周知，简历的内容（工作经历和项目经验）如果能和目标岗位相匹配的话，将会大大提高录用的概率。**因此需要给不同岗位定制不同简历。**

但是，每个岗位和公司的侧重点不同，定制起来是麻烦且繁琐的过程。

因此我实现了基于 AI 大模型的自动简历生成&排版，可以实现：

- 根据你的过往工作经验和项目经历选择最合适的条目；
- 根据目标工作岗位进行条目的匹配；
- 自动完成简历的排版并支持格式的调节；
- 免费、免费（只是用任意chat和一个开源项目）

考虑到大环境寒冬已至，有很多草友也面临相同的问题和需求，故分享出来供草友们一起交流。

> 前期你自己的实际的简历也是必要的，毕竟 AI 再怎么强大，我们求职还是要根据自身情况攥写。

## 0x1 AI的配置

实现这个流程的AI调用非常简单。

无需skills，直接在任意AI模型的chat界面，新建一个角色。

> 不同的大模型名称不同，Gemini叫Gem，ChatGPT叫GPTs，我以Gemini进行演示

### 操作流程：

1. 新建Gem：进入Gemini登录，点击左侧的Gem标签栏，之后点击右侧的[新建Gem]

![](https://raw.githubusercontent.com/HANDSOMEskuld/pics/main/2026/20260429225542506.png)

2. 配置Gem：自行填写[名称]和[说明]，在[指令]栏中填写Gem的prompt：



![](https://raw.githubusercontent.com/HANDSOMEskuld/pics/main/2026/20260429224632111.png)


3. 上传简历：在下面的[知识]区域上传你所有的简历、项目文件。

在这里我上传了我之前不同格式、文稿、工作岗位的简历信息，它们包含了我所有的工作内容和项目经验。


![](https://raw.githubusercontent.com/HANDSOMEskuld/pics/main/2026/20260429225210112.png)

4. 完成创建：点击右上角的[保存]按钮完成Gem的创建。

> 不要和别人分享你的Gem，因为这样他人会看到你的简历信息。注意隐私。

5. 简历定制：打开刚刚创建的Gem对话页面，把岗位信息和要求发送给Gemini。稍等片刻Gemini便会把符合岗位的简历json文件发给你。

点击代码框右上角的下载图标，下载json文件备用。

![](https://raw.githubusercontent.com/HANDSOMEskuld/pics/main/2026/20260429231045778.png)


## 0x2 简历排版

在上面获得定制的简历 json 文件之后，可以借助下面这个开源项目，对 json 格式进行一键的排版和定制：

- 项目代码：https://github.com/JOYCEQL/magic-resume
- 项目网站：https://magicv.art/app/dashboard/resumes

> 不需要进行部署，直接打开下面的项目网站就可以使用。

### 排版流程：

1. 简历导入：打开上面的项目网站，选择我的简历标签，直接点击右侧的导入简历。

选择导入 JSON 格式，选择刚才下载的 JSON 代码。

![](https://raw.githubusercontent.com/HANDSOMEskuld/pics/main/2026/20260429231823353.png)

2. 排版定制：导入成功之后，你就可以根据自己的审美来进行排版和定制。

- 在右侧可以直接选择模板，切换整体的风格；
- 在左侧可以对每一条进行编写、修改、排序。
- 还有其他功能和布局可以参照下面图片。

![](https://raw.githubusercontent.com/HANDSOMEskuld/pics/main/2026/20260429232452705.png)

3. 导出简历：在修改完成满意之后，可以直接点击右上角，进行 PDF 的导出。
